# Movie Ticket Calculator

A Python script that calculates the final price of a movie ticket based on user details and preferences.

## Description

This project was built as part of the freeCodeCamp Python curriculum. It uses conditional logic to determine ticket eligibility, apply charges, and calculate a final ticket price.

## How It Works

The script evaluates the following inputs:

- **Age** — determines eligibility to book and access evening shows
- **Seat type** — Premium, Gold, or Standard each carry different service charges
- **Show time** — evening shows carry an extra charge
- **Weekend** — weekend shows carry an extra charge
- **Membership** — members aged 21 and above qualify for a discount

## Pricing Breakdown

| Factor | Value |
|---|---|
| Base price | $15 |
| Evening/weekend surcharge | +$2 |
| Premium seat service charge | +$5 |
| Gold seat service charge | +$3 |
| Standard seat service charge | +$1 |
| Membership discount | -$3 |
